댕댕이로 보는 단계별 예시
:

```text
[미리 만들어둔 것]                    [사용자가 방금 올린 것]
25개 견종 Prototype                   믹스견 1마리의 embedding
= 견종별 "대표 외형 좌표"              = 이 강아지의 "외형 좌표"
```

**1단계 — 사전 준비 (증명사진 DB 만들기)**

골든리트리버 사진 50장을 모아서 각각 embedding으로 바꾸고 평균을 냅니다:

```text
골든 50마리 (색도 조금씩 다르고, 포즈도 다름)
      ↓ encoder
50개의 벡터
      ↓ 평균
"가장 골든리트리버다운 외형 좌표" = Golden Prototype
```

개별 골든의 특이함(유난히 진한 색, 이상한 포즈)은 평균 내면서 씻겨나가고, 골든 공통의 특징(늘어진 귀, 황금색 곱슬 털, 깃털 꼬리, 순한 주둥이 비율)만 남은 좌표예요. 이걸 25개 견종마다 하나씩 만들어둡니다. **여기까지가 "학습"이고, 서비스 시작 전에 끝나 있어요.**

**2단계 — 사용자 등장**

사용자가 믹스견 "보리" 사진을 올립니다. 보리는 엄마가 푸들, 아빠가 코커스패니얼인 애라고 해봐요.

```text
보리 사진 → YOLO가 보리 위치 찾음 → crop → encoder → 보리의 embedding (좌표 1개)
```

**3단계 — 대조**

보리의 좌표를 25개 prototype 좌표와 하나씩 거리 재봅니다:

```text
보리 vs Poodle prototype           → 0.84  ← 곱슬 털, 둥근 얼굴이 닮음
보리 vs Cocker Spaniel prototype   → 0.79  ← 늘어진 귀, 주둥이가 닮음
보리 vs Maltese prototype          → 0.61
보리 vs Golden prototype           → 0.55
보리 vs Husky prototype            → 0.12  ← 하나도 안 닮음
... (25개 전부)
```

**4단계 — 출력**

```text
보리의 외형 분석 결과:
Poodle           ████████████ 41%
Cocker Spaniel   ██████████   35%
Maltese          ████         13%
Other            ███          11%
```

Unknown / OOD

보리는 개니까 max similarity(0.84)가 threshold를 넘어서 통과했지만, 만약 고양이 사진이 들어왔다면:

고양이 vs 25개 prototype 전부 → 최고가 0.35밖에 안 됨
      ↓ max-sim 0.35 < threshold(예: 0.55)
"현재 지원하는 품종만으로 설명하기 어렵습니다" ← Top-K로 안 가고 여기서 종료
